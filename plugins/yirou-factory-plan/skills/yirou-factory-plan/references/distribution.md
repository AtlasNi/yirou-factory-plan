# 依柔工厂方案的版本维护

- 统一来源：`https://github.com/AtlasNi/yirou-factory-plan`，私有仓库，默认发布分支 `main`。保留插件/技能标识 `yirou-factory-plan` 和市场标识 `yirou-factory`。
- 仅在维护者要求更新共享技能或工厂资源时发布新版；不因普通产品分析写入仓库，不代其他使用者发出协作者邀请或变更仓库可见性。
- 作者工作区的维护入口为 `skill-maintenance/export_yirou_plugin.py`，配置保存在同目录 `github-source.json`。该入口不在接收者的技能目录内；接收者更新需求由维护者处理。
- 修改作者版技能后，先同步个人与项目副本；若工厂表也更新，则先刷新内置资源及配件图片。再运行导出入口，生成分发版：新使用者使用内置资源且自行确认公开发布偏好，内容改变时递增插件补丁版本。
- 核对插件入口、引用文件、数据快照、版本和图片均一致，再将导出目录的文件提交至上述仓库。使用最新远程树为基础，保留其他文件；分支推进使用期望旧SHA检查，避免覆盖他人更新。不上传凭证、本地站点记录、整份工作簿或无关项目。
- 遇到失败保留提交状态并报告；本地导出不等于已上传，更不等于对方已更新。远程提交成功后记录实际提交SHA与版本。
- 使用者首次添加仓库来源并安装插件。私有仓库须有读权限。后续通过客户端刷新或 `codex plugin marketplace upgrade yirou-factory` 获取更新，建议更新后开启新任务。个人账号的实时推送、定时拉取和后台更新未在此技能中配置，不声称已自动同步到所有电脑。
